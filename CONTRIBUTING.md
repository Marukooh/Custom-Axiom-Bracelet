# Contributing

Contributions are welcome: bug reports, compatibility notes for new game versions, and pull requests.

This repository is **source-available, not open source**: see [LICENSE](LICENSE). You may read it
and fork it on GitHub only to prepare a pull request. Reusing, redistributing or porting any part of
it elsewhere is not allowed.

## How to contribute
1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Fork, make your change on a branch, and open a pull request against `main`.
3. Explain what you changed and how you tested it (game version from `meta/0.paver`, DMM version,
   the options you ticked and the relevant lines of the DMM mount log).
4. Keep the mod's rules: DMM format 3 field-level edits only (records found by name, never fixed byte
   offsets), one independent option per buff, no game files in the repository.
